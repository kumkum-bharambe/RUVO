# Troubleshooting

## Installing

**Chrome says "This type of file can harm your device".**
Normal for any app file from a website. Tap **Download anyway**.

**Nothing happens after the download finishes.**
Open the **Files** or **Downloads** app, find **Ruvo.apk** and tap it.

**"Your phone is not allowed to install unknown apps from this source".**
Tap **Settings**, switch on **Allow from this source**, press **Back**, then tap **Install**. If you opened the file
from the Files app, the switch is for the Files app instead of Chrome; that is fine.

**Play Protect says "Unsafe app blocked" or "App not recognised".**
Ruvo is not from the Play Store, so Google does not know its developer. Tap **More details → Install anyway**.
Ruvo asks for no SMS, contacts, location, camera or microphone permissions.

**Play Protect only offers "OK", with no "Install anyway".**
Some phones are set to block every app from outside the Play Store. Please tell the developer the phone model;
do not switch off Play Protect to get round it.

**"App not installed" or "The package appears to be invalid".**
The download was probably cut short. Delete Ruvo.apk from Downloads and download it again on a steady connection.
If a version of Ruvo is already installed, uninstall it first.

**"There was a problem parsing the package".**
The phone is older than Android 8. Ruvo cannot run on it; please try another phone.

**Not enough space.**
Ruvo needs about 100 MB to install. Free some space and try again.

## Using the app

**I forgot my PIN.**
On the PIN screen tap **Forgot PIN?** → **Reset Ruvo**. Because nothing is stored online, this starts the app
afresh; sample students can be picked again at once.

**The numbers are different from the testing guide.**
The sample student's spending is set relative to today, so runway days and amounts change from day to day.

**Hindi in a book does not work.**
Translating a book to Hindi downloads a language pack once and needs Google Play services and internet. The chat's
Hindi works without it.

**"Listen" or the speaker button is silent.**
Turn up the media volume. Reading aloud uses the phone's own text-to-speech; on a few phones it has to be
switched on in **Settings → Accessibility → Text-to-speech**.

**The SMS switch is missing.**
The downloadable version does not read SMS, on purpose. Add payments with **+** or by dragging the pet down;
sample students already have sample bank payments.

**The app looks too dark or too light.**
Profile → Settings → **Daybreak** (light) or **Night swim** (dark), or **Follow my phone**.

**Something else.**
Uninstall Ruvo, install it again and pick a sample student. If the problem stays, note the phone model and what
you tapped, and tell the developer.
